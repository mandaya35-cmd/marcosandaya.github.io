# Marcos Andaya | Portfolio

Personal portfolio for Marcos Andaya, Virtual Assistant & Operations Support.

## Publish on GitHub Pages
1. Create a new repository (for example `marcos-andaya-portfolio`).
2. Upload everything in this folder: `index.html`, `assets/`, `.nojekyll`, `README.md`.
3. Go to **Settings → Pages**, set **Source** to `Deploy from a branch`, choose `main` and `/ (root)`, then save.
4. Your site goes live at `https://<your-username>.github.io/<repository-name>/` within a minute or two.

Tip: name the repository `<your-username>.github.io` to get the shorter address `https://<your-username>.github.io/`.

## Change the photo
Replace `assets/marcos.jpg` with a new image of the same name (portrait works best, about 1000px wide).
